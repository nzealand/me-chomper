# Me-Chomper

An original, camera-powered maze-chase browser game. Take a selfie (processed locally in the browser), chomp peas, and dodge the Boo-tanical garden spirits.

Run it from a local web server so camera permissions work:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`. Use arrow keys or WASD on desktop and swipe on mobile.
